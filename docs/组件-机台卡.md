# 机台卡 MachineCard

设置页「门店 → 机台」里的一个机台。它回答三件事：这台机叫什么、它有哪几个卡头、要不要合并成一块码表。

## 解剖

```
┌──────────────────────────────────────────────────┐
│  城堡精灵          4 个卡头                        │  head
│  ┌────────┐┌────────┐┌────────┐┌────────┐        │
│  │ 379347 ││ 379377 ││ 379416 ││ 385539 │        │  comms
│  └────────┘└────────┘└────────┘└────────┘        │
│  [改]  合并成一台   删除                           │  foot
└──────────────────────────────────────────────────┘
```

| 槽位 | 元素 | 内容 |
|---|---|---|
| head | `h3.machine__name` | 机台名，卡片里唯一的大字 |
| head | `span.machine__meta` | 卡头数量；共用时追加「共用码表」 |
| comms | `ul > li.chip` | 每个卡头一个等宽数字胶囊 |
| foot | `button` | 改（唯一描边）、合并（文字）、删除（文字） |

**一个东西领读**：机台名 18px/600，卡头 12px 等宽，动作 13px。三层递减，眼睛先落在名字上。

## 变体

| 变体 | 触发条件 | 与默认的差异 |
|---|---|---|
| `view` | 默认 | 名称 + 计数 + 卡头 + 三个动作 |
| `view--single` | 只有 1 个卡头 | 不出现「合并成一台」 |
| `view--merged` | 1 个单元挂多个卡头 | 计数追加「共用码表」，不出现合并 |
| `edit` | 点「改」 | 名称变输入框、卡头变输入框 + `×`、末尾虚线 `+`、动作换成保存/取消 |
| `empty` | 该店没有任何机台 | 列表级空态，不是卡片变体 |

## 尺寸

只有一档，密度优先（一个店最多 52 台）。

| 项 | 值 | token |
|---|---|---|
| 卡内边距 | 20 | `--space-5` |
| 卡头高度 | 20 | `--space-5` |
| 动作高度 | 30 | `--ctl-h-sm` |
| 卡间距 | 12 | `--space-3` |
| 圆角 | 16 | `--radius-xl` |
| 列宽 | `minmax(min(24rem, 100%), 1fr)`，`auto-fit` | - |

## 八状态

| 状态 | 表现 | 实现 |
|---|---|---|
| default | 白底，`--line` 描边，`--shadow-card` | - |
| hover | 边框升到 `--line-2`，阴影升到 `--shadow-pop` | `.machine:hover` |
| focus-visible | 2px 蓝色焦点环 | `--shadow-focus-ring` |
| focus-within | 卡片边框变蓝 + 1px 环 | `.machine:focus-within` |
| active | 按钮底色 `--hover-2` | `.btn:active` |
| editing | 同 focus-within，名称下方虚线 | `[data-editing]` |
| saving | 保存按钮转圈，`aria-busy`，卡片标 `data-saving` | `.btn[data-loading]` |
| error | 名称为空 / 卡头全空：toast 报错并聚焦到出错的框 | `toast()` + `focus()` |

## Token 映射

| 用途 | token |
|---|---|
| 卡面 / 描边 | `--card` / `--line` → `--line-2`(hover) |
| 机台名 | `--text-lg` / `--weight-semibold` / `--ink` |
| 计数 | `--text-xs` / `--ink-3` |
| 卡头 | `--text-xs` / `--font-mono` / `--ink-2` |
| 卡头底 | `--hover` / 边框 `--line-2` |
| 主按钮 | `--accent` / `--on-solid` |
| 焦点 | `--shadow-focus-ring` |
| 间距 | `--space-1..5`、`--space-0.5` |

## 无障碍

- `article` + `aria-labelledby` 指向 `h3`，屏幕阅读器读「城堡精灵，分组」
- 卡头列表 `ul[aria-label="城堡精灵 的卡头"]`
- 按钮 `aria-label` 带机台名：`改机台 城堡精灵`、`删除机台 城堡精灵`
- 卡头数量变化走 `aria-live="polite"` 的隐藏区（`#machineLive`），增删后播报「现在 3 个卡头」
- 键盘：Tab 依次 名称 → 卡头 → `×` → `+` → 保存 → 取消；`Enter` 保存，`Esc` 取消
- 删除不可撤销，走确认对话框（焦点陷阱 + Esc 取消）
- 颜色不单独承载信息：共用与否用文字「共用码表」，不靠颜色

## 已验证 / 未验证

- 静态 gate：无 emoji、无原生 select、无硬编码值、CSS 变量全部有定义、id 引用无悬空 — 全通过
